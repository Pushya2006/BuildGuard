# BuildGuard

Automated Software Supply-Chain Evidence and Verification Using SLSA-Aligned CI/CD.

## Status

Project foundation stage. Application and test scaffolding only.

## Setup (Windows PowerShell)

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

## Run the application

```powershell
python app/main.py
```

## Run tests

```powershell
python -m pytest
```
